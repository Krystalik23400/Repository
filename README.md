# Telegram-бот для данных DEX

Бот показывает цену, изменение и объём за 24 часа, ликвидность и сеть торговых пар. Основной источник данных — DEX Screener. Если он возвращает HTTP 403, бот запрашивает данные у GeckoTerminal и указывает источник в ответе.

## Запуск

1. Создай бота командой `/newbot` у [@BotFather](https://t.me/BotFather).
2. Запусти `python bot.py` из папки репозитория. Нужен Python 3.10 или новее. Дополнительные пакеты не требуются.
3. Вставь токен в терминал и нажми Enter. При вводе символы скрыты. Для запуска без запроса токена задай переменную окружения `TELEGRAM_BOT_TOKEN`.
4. Открой ссылку на бота из терминала и отправь `/start` в личном чате.

## Команды

- `/coin SOL` — поиск по названию или тикеру. Для поиска пары можно отправить `SOL/USDC`.
- `/address solana So11111111111111111111111111111111111111112` — поиск по сети и адресу токена.
- `/help` — подсказка по командам.
